# FlowDay 5.0-a Beta（Android）测试计划

> 目标：在真实 Android 设备上验证「脱离浏览器的独立应用」体验与数据安全底线。
> 原则：**任何数据丢失/覆盖问题为 P0，立即停止扩散并反馈。**

---

## 1. 测试范围与优先级

| 优先级 | 模块 | 说明 |
|---|---|---|
| P0 | 安装/启动/图标/独立运行 | 不依赖浏览器；桌面图标独立启动 |
| P0 | 数据持久化 | 新建/编辑/删除后杀进程重开数据仍在 |
| P0 | 数据升级保留 | 覆盖安装后数据不丢、不被示例数据覆盖 |
| P0 | 隐私 | 不上传任务内容；权限列表仅联网 |
| P1 | 任务/项目 CRUD | 创建、编辑、删除、撤销、归档、恢复 |
| P1 | 界面与交互 | 液态玻璃、深浅色、弹窗、Toast、底部导航 |
| P1 | 输入与键盘 | 软键盘弹出时表单/按钮可见可点 |
| P1 | 返回键 | 页内回退、首页退出、弹窗 Esc/返回关闭 |
| P2 | 刘海屏/状态栏/横竖屏 | 无遮挡、无错位 |
| P2 | 日历/习惯/统计 | 功能可用、数字正确 |
| P2 | 备份导出/导入 | 导出文件可用、导入校验生效 |

## 2. 用例清单（建议逐条勾选）

### A. 安装与启动
- [ ] A1 全新安装成功，桌面出现 FlowDay Beta 图标
- [ ] A2 点击图标独立打开（地址栏/浏览器不出现）
- [ ] A3 设置 → 关于 显示 versionName `5.0-a-beta.1`、versionCode 1、commit、构建时间
- [ ] A4 系统权限页中该应用仅显示「联网」类权限（无通讯录/位置/存储等）
- [ ] A5 飞行模式下冷启动可用（资源在包内）

### B. 数据持久化
- [ ] B1 新建 3 条任务 + 1 个项目 → 杀进程（最近任务划掉）→ 重开数据仍在
- [ ] B2 重启手机 → 重开数据仍在
- [ ] B3 覆盖安装同版本/更高 versionCode APK → 数据保留且不被示例数据替换
- [ ] B4 编辑任务标题/日期/优先级 → 重开为修改后的值
- [ ] B5 删除任务 → 8 秒内点「撤销」恢复；超时后不再恢复
- [ ] B6 导出备份 → 文件存在且可被电脑端 FlowDay 导入校验通过

### C. 功能 walkthrough
- [ ] C1 引导：首次进入出现 3 步引导；跳过后可在设置重看；完成后不再自动出现
- [ ] C2 项目：创建/改名/换色/归档/恢复/删除（删除后任务在「未分类」）
- [ ] C3 任务：快速添加、编辑、完成/取消完成、筛选、搜索
- [ ] C4 日历：月/周/日切换、给任务排时间
- [ ] C5 习惯：打卡/撤销、连续天数显示
- [ ] C6 今日：焦点列表、进度环、7 日柱状、时间线

### D. 交互与显示
- [ ] D1 浅色/深色/跟随系统三态正常，玻璃层次可见
- [ ] D2 弹窗：打开聚焦首输入、Tab 循环、返回键关闭、关闭后焦点合理
- [ ] D3 软键盘弹出时：任务/项目编辑弹窗的保存按钮可见可点（必要时滚动）
- [ ] D4 底部导航 5 项可点、当前项高亮；任务页「任务/项目」分段可切换
- [ ] D5 刘海屏/挖孔屏：顶部内容不被遮挡；底部手势条不压住导航
- [ ] D6 横屏不崩溃、布局可用（允许非最优）
- [ ] D7 长列表（>200 任务）滚动流畅、无整页卡顿

### E. 多窗口与异常
- [ ] E1 分屏/小窗模式下可用
- [ ] E2 应用被系统回收后重开，数据一致
- [ ] E3 存储满/私有目录被清理等异常下不静默丢数据（出现明确提示）

### F. 隐私与安全
- [ ] F1 飞行模式 + 抓包（可选）：无任务内容外发
- [ ] F2 设置中 AI 为演示模式说明清晰；未开启真实模型调用
- [ ] F3 应用内无 API Key/凭据展示；导出备份不含凭据

## 4. 退出标准

- P0 用例 100% 通过；
- P1 用例通过率 ≥ 95%，且失败项均有明确规避说明；
- 无 P0/P1 级数据丢失或覆盖问题；
- 至少 3 台不同厂商设备（含 1 台 Android 10 以下）完成 A–D 组。

## 6. Beta.2 追加验收组（Liquid Glass 与 Android 原生适配）

### G. 液态材质观感（对照 docs/phase5.0/lg-evidence/curated 的 after 图）
- [ ] G1 顶部导航、底部胶囊、菜单、弹窗呈现**半透明液态玻璃**（可见边缘高光与内部光带），而非纯白卡片
- [ ] G2 滚动内容经过导航下方时，能看到内容被玻璃模糊并透色（环境响应）
- [ ] G3 底部导航切换时，选中块**滑动过去**（不是淡入），动画结束后位置稳定
- [ ] G4 任务/项目卡片为**清晰的白底材质**（不是全部玻璃），长文可读
- [ ] G5 深色模式下玻璃有层次：导航比背景亮、卡片比背景略亮、阴影自然
- [ ] G6 打开/关闭弹窗与菜单时无闪烁、无"突然出现"；关闭动画结束后焦点正常
- [ ] G7 系统开启「减少动态效果」后，动画明显收敛但不影响可用性
- [ ] G8 系统开启「移除透明度/高对比度」后，玻璃变实底且文字更清晰

### H. Android 系统区域（真机必测）
- [ ] H1 状态栏文字/图标不被导航玻璃遮挡；浅色主题下状态栏图标为深色，深色主题下为浅色
- [ ] H2 底部手势条不压住底部导航；横屏时左右安全区正常
- [ ] H3 软键盘弹出时，编辑弹窗的保存按钮可见可点（视口被压缩而非遮挡）
- [ ] H4 双指无法缩放整页；但系统字体/显示大小调大后布局仍可用（不截断文字）
- [ ] H5 返回键：页内后退 → 首页再按退出应用
- [ ] H6 分屏/小窗下布局可用，无横向滚动条
- [ ] H7 320px 等效窄屏（如小屏手机 + 大字体）无横向溢出

### I. 数据与回归（不因视觉重构退化）
- [ ] I1 新建/编辑/删除/撤销/归档后杀进程重开数据一致
- [ ] I2 覆盖安装 Beta.2 后 Beta.1 的数据完整保留
- [ ] I3 多标签/多窗口下并发编辑出现冲突提示，三选一后不丢数据
- [ ] I4 导出备份 → 清空 → 导入恢复一致
- [ ] I5 首页进度、日历、习惯打卡数字正确

## 5. 已知未验证项（发布前如实告知测试者）

- 自动化环境无 Android 模拟器/真机：安装、启动、持久化等 P0 项**以真机人工测试为准**；
- 不同厂商 WebView 差异（尤其旧版 WebView）可能出现渲染差异；
- 折叠屏/平板布局未专项适配（按手机布局拉伸）。
