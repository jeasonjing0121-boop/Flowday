# FlowDay 5.0-a Beta（Android）安装指南

> 适用对象：Beta 测试用户
> 安装包：`FlowDay-5.0-a-Beta.2.apk`（本次交付）· 旧版 `FlowDay-5.0-a-Beta.1.apk`（保留，可对照回滚）
> 独立安装，**无需浏览器、无需联网**
> 版本：5.0-a-beta.2（versionCode 2）· 包名 `app.flowday.beta` · 签名与 Beta.1 相同（可直接覆盖升级，数据保留）

---

## 0. 安装前须知

- 本版本为**测试版**，与未来正式版使用不同包名（`app.flowday.beta`），可与正式版共存、互不覆盖。
- 应用**不申请任何敏感权限**：仅 Android 默认的联网权限（用于未来可选功能；当前版本数据完全本地保存，不上传）。
- 你的任务、项目、习惯数据**只保存在手机本地**（应用私有 IndexedDB），卸载应用会清除数据，请先在「设置 → 数据」导出备份。
- 安装包使用 FlowDay Beta 专用签名证书签名；安装时系统可能提示「未知来源应用」，属正常现象。

## 1. 系统要求

| 项 | 要求 |
|---|---|
| Android 版本 | **Android 7.0（API 24）及以上** |
| 存储 | 安装约 15 MB；数据随使用增长 |
| 网络 | 安装与使用均**不需要**网络 |
| WebView | 系统自带 Android System WebView（Android 7+ 均满足） |

## 2. 安装步骤（手机侧）

1. 通过测试群/网盘/数据线等方式取得 `FlowDay-5.0-a-Beta.2.apk`（核对 SHA-256，见 `SHA256.txt`）。
2. 在文件管理器中点击该 APK。
3. 若系统提示「禁止安装未知应用」：
   - 按提示进入「设置 → 应用 → 特殊应用权限 → 安装未知应用」；
   - 为你使用的文件管理器/浏览器开启「允许安装应用」；
   - 返回后重新点击 APK。
4. 点击「安装」，等待完成。
5. 桌面/应用抽屉出现 **FlowDay Beta** 图标（晨光渐变 F 标记）。
6. 点击图标**独立启动**（不会打开任何浏览器）。

### 通过 ADB 安装（可选，开发者/测试组长）

```bash
adb install -r FlowDay-5.0-a-Beta.2.apk
# 校验已安装：
adb shell pm list packages | findstr flowday
# 启动：
adb shell monkey -p app.flowday.beta -c android.intent.category.LAUNCHER 1
```

## 3. 校验安装包完整性（建议）

在电脑上执行（Windows PowerShell）：

```powershell
Get-FileHash .\FlowDay-5.0-a-Beta.2.apk -Algorithm SHA256
```

将输出与 `SHA256.txt` 中的值逐字符比对；不一致请勿安装并联系测试负责人。

## 4. 首次启动

1. 启动后进入**上手引导**（3 步：欢迎 → 建项目 → 第一条任务），可跳过。
2. 引导完成后进入「今日」页；数据立即开始本地保存。
3. 在「设置 → 关于」可核对：测试版本标识、versionName/versionCode、构建时间与 Git commit。

## 5. 升级与卸载

- **升级**：直接安装新版本 APK（相同签名、versionCode 更大）即可，**本地数据保留**；Beta.1 → Beta.2 已按此方式验证签名与版本递增。
- **新版视觉提示**：Beta.2 为 Liquid Glass 材质重构，导航/浮层为半透明液态玻璃，内容可在其下滚动；系统状态栏与手势条区域由应用自动避让。
- **卸载**：系统设置 → 应用 → FlowDay Beta → 卸载（数据随之清除，请先导出备份）。
- 不要通过第三方「清理/分身」工具迁移应用数据，可能造成 IndexedDB 损坏。

## 6. 常见问题

| 现象 | 处理 |
|---|---|
| 安装时提示「解析软件包时出现问题」 | 确认下载完整（SHA-256 一致）；确认 Android ≥ 7.0 |
| 启动后白屏 | 强制停止后重开；仍复现请记录机型/Android 版本/WebView 版本并反馈 |
| 状态栏/手势条压住内容 | Beta.2 已做安全区适配；若出现请记录机型与是否开启「全屏手势/沉浸模式」 |
| 页面仍可双指缩放 | 记录机型与 WebView 版本（应用内已禁用缩放，系统字体放大仍生效） |
| 返回键直接退出 | 在首页时返回键退出属预期；页内返回会先回到上一页 |
| 想清空重来 | 设置 → 数据 → 清空本地数据（有二次确认） |
| 多窗口/分屏使用 | 支持；数据一致性由内置版本机制保护，冲突时会提示三选一 |
