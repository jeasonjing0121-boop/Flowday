## 2. 功能交付清单

### D0 数据安全（最高优先级）
- `initializeStorage` 失败路径返回显式 `blocked`（`schema-too-new` / `corrupt` / `read-failed` / `unavailable` / `migration-conflict`），保留既有 `InitResult` 字段以兼容旧测试与调用方。
- `PersistenceController`：阻断即永久关闭持久化；**绝不写入种子数据**；首写 CAS 失败时载入库中快照而非覆盖；`requestSave`/`flush` 双重阻断护栏。
- `AppStore`：初始 React 状态改为 `emptyData()`（不再以 demoData 作初始态）；阻断时跳过数据 dispatch、通道监听与自动保存。
- `BlockedScreen`：按原因展示文案，明确「未写入任何数据」，提供原始数据导出（只读）与二次确认的清除入口。
- `exportRawData()`：读出原始记录 + 同步元信息 + 旧 localStorage 载荷，用于证据留存；全程只读。

### D1 项目数据层
- `Project` 新增可选 `archived` / `createdAt`；`Settings` 新增可选 `onboarded`；**schemaVersion 保持 2，不升级数据库**。
- sanitize 保留新字段、缺失补默认、非法布尔修正并计数，`archivedProjects` 统计；旧备份/旧数据继续保持可导入。
- reducer：`project/add`、`project/update`、`project/archive`、`project/delete`（**仅解除任务关联，永不删除任务**，单次状态变更 → 单次 CAS 保存）、`data/repairOrphanProjects`。
- 纯函数模块 `lib/projects.ts`：名称/颜色规范化、稳定排序、批量统计（单遍）、未知引用解析、孤儿检测、`makeProject`。

### D2 项目管理界面
- `/projects` 列表：卡片（进度条、完成率、本周进度）、归档折叠区与恢复、空状态 CTA、孤儿引用维护卡片。
- `/projects/:id` 详情：完成率环、未完成/已完成/本周/总计、任务分组（复用 `TaskRows` 虚拟列表）、新建任务、编辑/归档/删除、未知 id 空态。
- 项目编辑器（名称校验 + 8 色 radiogroup + Enter/Esc + 自动聚焦）、删除弹窗（明确「任务不会被删除」）。
- 桌面侧边栏新增「项目」；移动端底部导航**保持 5 项**，任务页新增「任务 / 项目」分段入口。
- 任务编辑器：分类下拉按活动/已归档分组、孤儿占位项、内联「新建项目」并自动回填。

### D3 删除撤销
- `ToastProvider` 新增 `toastAction()`（动作按钮 + 8s 时长 + 去重键），普通 `toast()` 行为不变。
- `UndoProvider`：删除立即生效并落库；撤销为补偿性 `task/add`（同一快照），走既有 CAS；若 id 已存在则幂等跳过；连续删除仅最后一次可撤销。
- `TaskRow` 保留既有确认弹窗，删除委托给撤销提供者。

### D4 PWA
- `manifest.webmanifest`（standalone、zh-CN、192/512 + maskable、apple touch icon）。
- `public/sw.js`：预缓存应用壳；导航 network-first（3s）→ `index.html` 回退；`/assets/*` cache-first；manifest/图标 stale-while-revalidate；其余同源 GET 与 `/api`、带 Authorization、跨域一律**不缓存**；激活仅清理 `fd-` 前缀旧缓存。
- 注册仅在**生产构建**；新版本只提示（`UpdateBanner` + 设置页「检查更新」），用户确认才 `SKIP_WAITING`；单会话最多自动刷新一次，防循环。
- 图标由 `tools/gen-icons.py` 离线生成并提交（仓库不引入图片依赖），源 SVG 留存。

### D5 首次引导
- 三步向导（欢迎/隐私 → 建项目 → 第一条任务），每步可跳过；`isOnboardingEligible` 纯规则（就绪、未阻断、未完成、非示例数据、项目/任务/习惯/打卡全空）。
- 完成或跳过写入 `settings.onboarded`，之后不再自动弹出；设置页「重新查看上手引导」进入**回顾模式**，不重置标记、不写库。
- 空状态：项目页 CTA、任务页「先创建第一个项目」、今日页/习惯页沿用既有 CTA。

### D6 验证与修复
- 新增 5 套 E2E：`e2e-projects`（30）、`e2e-undo`（20）、`e2e-onboarding`（16）、`e2e-datasafety`（14）、`e2e-pwa`（14），共 **94 项**，全部通过。
- 新增 `perf-5a` 性能复核脚本（dev 埋点 + prod IndexedDB 口径）。
- 回归中发现并修复两个真实问题：
  1. 首次安装「种子写入 + dispatch 回声」导致多写一次（revision 1→2，多标签首启时序抖动）→ 新增 `seeded` 标记，上层用 `markExternalReplace` 跳过回声；修复后首启稳定为 revision 1。
  2. 连续删除时撤销 Toast 堆叠多个按钮 → Toast 去重键，仅保留最新一个撤销入口。
