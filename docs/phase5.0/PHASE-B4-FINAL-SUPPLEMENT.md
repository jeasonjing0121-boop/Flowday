## 三、边缘尺寸测量（CSS px ↔ 设备物理像素）

换算基准：**1 CSS px = 3.5 设备物理像素**（1260÷360 = 3.5，density 560dpi）。

### 3.1 浅色 · 底栏顶边（逐行亮度剖面，x=600..660）

| 特征 | 位置（设备 y） | 实测宽度 | 换算 CSS px | CSS 设计值 |
|---|---|---|---|---|
| 外侧反射带（边缘外亮环） | 2280–2282 | 3 px | 0.86 px | 外圈 0.6px 暗线 + 2px 柔环的白边部分 |
| **外侧暗线（核心）** | **2283–2287** | **4–5 px** | **1.14–1.43 px** | 外圈 `0 0 0 0.6px`（=2.1px）+ 柔环 `2px`（=7px），抗锯齿后峰值 4–5px |
| 内侧亮线（边缘高光） | 2288–2290 | 2–3 px | 0.57–0.86 px | `inset 0 1px 0`（=3.5px）+ `inset 0 0 0 0.75px`（=2.6px） |
| **边缘→玻璃体过渡带** | 2283–2290 | **8 px** | **2.29 px** | 双边缘合计 |
| 折射带范围（自边缘向内） | 2283–2318（10 CSS px） | 35 px | 10 px | `--lg-refract-w: 10px` ✅ 实测亮度 0.146 → 0.736（Δ0.59） |

### 3.2 浅色 · 页头下边（逐行亮度剖面，x=600..660）

| 特征 | 位置 | 实测宽度 | CSS px | 说明 |
|---|---|---|---|---|
| 内侧亮线（下边缘高光） | 737–738（L=0.964 峰值） | 2 px | 0.57 px | 比玻璃体（L≈0.95）高 +0.014 |
| 玻璃厚度阴影 | 739–741 | 3 px | 0.86 px | L 由 0.93 渐降 |
| **外侧暗线** | **742–743** | **2 px** | **0.57 px** | L=0.360（明暗差 −0.57） |
| 下方落影过渡 | 744–748 | 5 px | 1.43 px | L 0.55→0.62 渐变 |
| **整体边缘过渡宽度** | 737–748 | **12 px** | **3.43 px** | 亮线+厚度+暗线+落影 |

### 3.3 深色 · 底栏顶边

| 特征 | 实测宽度 | CSS px |
|---|---|---|
| 外侧暗线 | 4 px | 1.14 px |
| 内侧亮线 | 2 px | 0.57 px |
| 边缘→玻璃体过渡 | 9 px | 2.57 px |
| 折射带（35px 内）亮度变化 | 0.132 → 0.594（Δ0.46） | — |

### 3.4 结论

- 浅色下**外暗线可见宽度约 1.1–1.4 CSS px**、**内亮线约 0.6–0.9 CSS px**，二者合计形成 **2.3–3.4 CSS px 的双边缘厚度带**；
- 与 CSS 设计的 `0.6px` 外圈 + `1px`/`0.75px` 内圈在高 DPR 下抗锯齿后的表现一致（设计值×3.5 经抗锯齿与模糊衰减后为实测峰值）；
- **折射带实测恰好覆盖自边缘向内的 10 CSS px（35 设备 px）**，与 Token `--lg-refract-w: 10px` 完全吻合，此区间内亮度变化 Δ0.46–0.59，构成"厚度/折射"观感。
