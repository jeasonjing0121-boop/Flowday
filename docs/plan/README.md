# FlowDay 完整方案 v1.0（总览）

> 状态：**待创始人确认** ｜ 日期：2026-11-13 ｜ 阅读本文约 10 分钟
> 本方案共 5 份分册 + 1 份合订本。建议先读本文，再按第 9 节挑需要的部分看。

**一句话**：FlowDay 是一个"**AI 帮你计划、但每一步都经你确认**"的个人效率工作台——任务、日程、习惯、数据放同一个「今日」界面，中价位、中文优先、精致克制。本方案已把产品、设计、技术、开发计划、商业模式拆成可执行文档；你确认后即可开工。

## 2. 十个关键决策（一页看懂）

| # | 决策 | 结论 | 一句话理由 |
|---|---|---|---|
| 1 | 产品定位 | 中价位、中文优先的 **AI 每日工作台**；"AI 建议，你拍板" | 避开 Todoist（无真规划）、Sunsama/Motion（贵、英文、黑盒自动排程）的空位 |
| 2 | 视觉方向 | **A「晨光纸感」**（浅色主，深色为独立设计的「夜航」） | 暖纸+墨黑+晨光渐变，在效率工具里辨识度高，白天办公与社媒传播都占优 |
| 3 | 前端技术 | React + TypeScript + Vite + Tailwind + TanStack（Router/Query）+ shadcn/ui | 登录后工具型应用无需 SSR；一套响应式代码覆盖桌面+手机浏览器；生态成熟好维护 |
| 4 | 后端技术 | Supabase（Postgres + Auth + RLS + Edge Functions）+ Vercel 静态托管 | 省掉 80% 服务器运维；行级权限+数据可迁移，不被单一厂商锁死 |
| 5 | AI 架构 | 服务端代理 + 供应商可切换（默认 DeepSeek flash）；**提案 → 确认 → 服务端执行** | 密钥不落客户端；换模型不改前端；模型再"幻觉"也只能生成一条你会拒绝的建议 |
| 6 | 额度与成本 | 免费 30 次/月、Pro 300 次/月（公平使用）；单次约 ¥0.01–0.03 | 1000 次/月会吃掉订阅收入；300 次覆盖约 95% 用户 |
| 7 | 跨平台 | 先做响应式 Web + PWA（可安装）；Phase 6 用 Expo 做原生 App，复用核心逻辑 | 一套代码先验证，再投原生；不建议 Capacitor 套壳（体验与 iOS 审核风险） |
| 8 | 商业模式 | 免费 + Pro **¥29/月、¥199/年（约 ¥16.6/月）、学生 ¥99/年**；海外 $6.99/月、$49.99/年 | 约为滴答清单年费 1.43 倍，用户能用"AI 每日计划+闭环"解释差价 |
| 9 | 开发节奏 | **约 5–6 周可邀请内测，7–8 周可商业化上线**（Web），之后 3–4 周原生 App | 按我每工作日推进、你阶段末验收 1–2 小时的估算；不承诺日历日期 |
| 10 | 最大风险 | 中国大陆访问 Supabase 稳定性 + 支付/备案/生成式 AI 合规 | 已给三个应对选项与决策触发条件；W1 即启动品牌/主体/支付咨询，Phase 4 前决策 |

## 3. MVP 一页纸

**MVP 判定标准**：一个普通用户能完整走完"注册 → 3 分钟引导 → 记下 3 个任务 → AI 给出可接受计划 → 完成勾选 → 打卡习惯 → 第二天看到进度"，且**全部在真实后端上运行、手机上可独立完成**。

| 模块 | MVP（P0）包含 | 不在 MVP（P1/P2） |
|---|---|---|
| 账户与引导 | 邮箱验证码登录、多端同步、3 步引导、注销与导出 | Google 登录、密码登录 |
| 今日 | 进度环、今日焦点、今日时间线、习惯速打卡、效率速览、AI 建议卡 | 今日收尾卡、模块自定义 |
| 任务 | 创建/编辑/删除/回收站、4 级优先级、截止时间、项目、子任务、4 种重复、完成撤销、分组排序筛选、**本地快速添加解析**、详情 | 批量操作、标签、拖拽排序、搜索、看板/模板 |
| 日程 | 日视图、周视图、任务拖入排程、独立日程事件、**冲突检测提示**、快速调整、未安排区 | 月视图、重复日程、外部日历同步 |
| 习惯 | 创建、每日打卡、连续天数、7/30 天完成率、简版详情 | 热力图完整版（P0 简版 30 天）、提醒、与任务联动 |
| AI | 对话、自然语言建任务、目标拆解、生成今日计划、**提案确认/拒绝/5 秒撤销**、额度显示 | 逐条选择、重排未完成、AI 周报、BYO Key、对话历史 |
| 统计 | 完成趋势、完成率与连续、分类分布 | 周期对比、AI 周报、黄金时段 |
| 设置 | 资料、深浅色、周起始/时区、AI 设置、导出、注销 | 通知、多语言、订阅管理（Phase 5 上） |
| 系统 | 响应式、四态（空/加载/错误/离线）、埋点、基础快捷键、反馈与法务入口 | 命令面板、PWA 安装引导、推送 |

需求总量：**P0 61 条**（其中 MVP 主体 56 条 + Phase 5 商业化 5 条）、P1 24 条、P2 9 条。完整清单与验收标准见 [01 PRD](./01-prd.md)。

## 4. 阶段路线（每个阶段都可运行、可验收）

| 阶段 | 你会看到什么 | 工期（估算） |
|---|---|---|
| **Phase 0 基建与登录** | 你用自己的邮箱注册登录，手机/电脑同一账号，换账号看不到数据；预览地址可访问；CI 全绿 | 3–4 天 |
| **Phase 1 任务与今日** | 真实任务的日常可用：记、分、排、完成、重复、快速添加 | 5–7 天 |
| **Phase 2 日历与习惯** | 安排明天的一天、冲突提示、习惯打卡与连续天数 | 5–7 天 |
| **Phase 3 AI 助手（核心）** | AI 建任务/拆目标/排今日计划，每次改动先给你看、你确认才生效 | 6–8 天 |
| **Phase 4 统计、设置 → 邀请内测** | 统计页、设置、导出/注销、安全与性能加固；邀请 20–50 人真实使用 | 5–7 天 |
| **Phase 5 商业化** | 定价页、支付、Pro 门禁、订阅管理；可以收第一笔钱 | 4–6 天 |
| **Phase 6 移动端** | iOS/Android 原生 App 上架（复用核心逻辑） | 3–4 周 |
| **Phase 7 持续迭代** | 按留存/转化数据迭代 P1 功能 | 长期 |

每个阶段都有明确的**出口门禁**（不通过不进下一阶段）与"你需要做什么"清单，见 [04 分阶段开发计划](./04-roadmap.md)。

## 8. 诚实的前提与声明

1. **工期是估算**：AI 辅助开发速度取决于测试返工与需求变更，我给区间不给承诺；阶段报告会及时修正预期。
2. **成本以 2026-11 官网价格估算**：Supabase、DeepSeek、Apple/Google 等费率可能变化，上线前以官网/账单为准。
3. **市场与付费意愿尚未验证**：定价与 Pro 权益是"有依据的假设"，需在 Beta 用真实数据验证（04 与 05 分册给了验证指标与实验计划）。
4. **品牌名未核查**：FlowDay 可能已被注册，Phase 0 必须先查商标/域名/商店重名。
5. **大陆合规未完成**：ICP 备案、生成式 AI 合规、数据出境是大陆商业化前置条件，方案给出务实路径，但不构成法律意见。
6. **不承诺"上线即成功"**：方案给出可验证的指标（激活、D7 留存、AI 采纳率、付费转化）与迭代机制，成功取决于执行与用户反馈。
