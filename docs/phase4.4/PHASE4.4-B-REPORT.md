## 2. 功能实现说明（摘要）

1. **导入预览**：选文件 → 大小/格式/版本/SHA-256/规范化校验 → 玻璃弹窗展示全部信息 → 确认 → 既有 `dispatch → 防抖 → CAS` 原子写入。校验失败红色横幅 + 禁用确认（不可绕过）。
2. **过期预览保护**：打开时记录权威 revision+writerId；轮询与确认前双重检查；**仅外部写入**（writerId 不同）判定过期 → 琥珀横幅 + 禁用；自身保存推进版本不误报。
3. **未保存修改**：预览捕获 + 确认复核 → 玻璃二次确认；取消不动数据。
4. **持久化状态**：真实查询 `persisted()`；申请后重新查询判定 granted/denied；unsupported/failed 明确文案；声明"仅本机、非云备份"。
5. **上次导出提醒**：仅导出成功后记录；失败不记录；空状态文案。
