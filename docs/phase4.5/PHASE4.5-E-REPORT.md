## 4. React 渲染与 CPU 分析

- **渲染范围受控**：任意规模下已渲染行恒为 44、DOM ≈1,137–1,144（虚拟滚动 + `React.memo` + `useDeferredValue` + 分组单遍聚合全部生效）。
- **聚合成本**：`__FD_AGG_MS__`（应用内自测量）dev 下 1k 1.6ms → 10k 9.7ms → 25k 21.9ms → 40k 45.1ms，线性；prod 端到端 Dashboard 就绪 194–516ms（含导航 + IndexedDB 整份读取 + 首帧）。
- **长任务**：单轮测量窗口（搜索 + 两次筛选）内 50ms+ 长任务 3–6 个；40k 时最长约 166.7ms（滚动测量中的长帧）。
- **搜索输入**：连续 5 次输入只触发 1 次筛选（防抖合并），IME 组合期过滤次数为 0（4.2 的 type5/IME 优化保持）。
- **无额外 memo 需求**：未新增任何 `memo/useMemo/useCallback`（本轮无产品代码修改）。

## 6. IndexedDB 压力与异常注入（9/9 通过）

| 场景 | 结果 |
|---|---|
| 10k 数据 40 次快速勾选 | 全部成功，revision 单调；**40 次点击合并为 1 次落库**（180ms 防抖，符合设计） |
| revision 与 meta 一致性 | 每次写入后 `app.revision == meta.revision`（CAS 单事务原子） |
| 事务 abort 注入 | 捕获 → `persistence=false` + Toast「保存到本地数据库失败，请检查浏览器存储空间」，无半写 |
| QuotaExceeded 注入 | 同上，明确反馈 |
| IndexedDB 不可用（文档创建前注入） | 应用仍渲染（不白屏）→ `persistence=false` + Toast「本地数据库不可用：当前环境不支持 IndexedDB；本次修改不会被保存」 |
| 移除注入后恢复 | 数据完好（10,000 条 / id 唯一 / revision 与 meta 一致） |
| 写入期间关闭页面 | 重载后数据一致、无半写、revision 不回退 |
| 持续写入下读取一致性 | 30 次读取：revision 单调、任务 id 唯一 |
| 导入校验和失败 | 预览拦截 + 确认禁用，库中 10,000 条数据不受影响 |

## 7. 多标签长期稳定性（15/15 通过）

- 3 标签 × 30 次并发勾选：每标签观察到的 revision 单调；写入后 `revision == metaRevision`；任务数 500、id 唯一（无静默丢失/重复）。
- 冲突路径（dirty 标签 + 外部写入）：冲突横幅出现 → **草稿立即写入 localStorage** → 「重新加载（推荐）」后横幅清除且 revision 不回退。
- 收敛：3 标签全部收敛（有横幅=用户可见冲突/或数据一致；无静默覆盖）。
- 5 标签主题 + 页面 churn（各 8 轮）：revision 一致、数据未损坏、无错误 Toast 刷屏、主题全局一致。
- 设计确认：dirty 标签检测到外部写入会**暂停自动保存并等待用户选择**（4.3 语义），因此并发写压测中 revision 前进次数有限属预期。

## 8. 异常注入汇总

见第 6 节；全部异常路径均有「明确用户反馈 + 安全降级 + 数据不损坏」三要素。headless 环境无法验证真实休眠恢复与浏览器强杀，已如实标注（沿用 4.5-D 结论）。

## 9. 关于 dashboardAggregate 模块级差异（>10% 偏差的分析）

- **现象**：模块级 `dashboardAggregate(10k)` 三独立页面轮次测得 12.6 / 11.4 / 7.1 ms（中位 11.4），4.2 报告为 6.1ms。
- **排除代码回归**：`src/lib/selectors.ts` 自 4.2 基线提交后**无任何修改**（`git log` 仅一次基线提交）；1k 规模测得 0.9–1.3ms，与 4.2 的 1.3ms **一致**。
- **证据指向环境/测量**：
  1. 跨轮次同规模波动达 ±40%（40k：30.6 → 43.2ms），说明本机在该时段存在明显噪声；
  2. 测量时本机已连续运行 2.5 小时以上压测（此前多轮浏览器/构建负载），存在热降频可能；
  3. 端到端 Dashboard 就绪与 4.2 场景无退化（prod 194–516ms），说明差异未传导到用户可见指标；
  4. 应用内自测量 `__FD_AGG_MS__`（dev）10k = 9.7ms（4.2 首聚合 8.0ms），偏差 +21%，处于同机噪声区间。
- **结论**：判为环境波动为主，**不触发代码修改**；若需严格判定，建议在专用基准机（空载、固定频率）复测。此为已知测量限制，已列入剩余风险。

## 14. 验收结论

- 端到端性能不劣于 4.2 历史基线（搜索/筛选/首帧显著更好），虚拟滚动与渲染优化在 1k–40k 全规模保持恒定 DOM 与行数；
- 长时间运行（501 次操作）无内存增长趋势，监听器/定时器/rAF/观察者/通道均有清理；
- 存储异常（abort/quota/IndexedDB 不可用/关闭期间写入）均有明确反馈与安全降级，数据不损坏；
- 多标签 3–5 并行长期运行 revision 单调、CAS 原子、冲突可见、草稿受保护、最终收敛；
- 唯一偏差为模块级聚合的测量环境差异（有证据链），未做无谓优化；产品代码仅修复了回归中发现的 1 处 a11y 触控尺寸缺陷。

等待验收；未进入 Phase 4.5-F。
